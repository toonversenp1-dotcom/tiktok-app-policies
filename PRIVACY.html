Privacy Policy

Effective: 2024-01-01

Data We Access (via TikTok OAuth)

When you authorize Video Autopilot, we receive:

  • TikTok username and display name
  • Profile avatar URL
  • Video upload and publish permissions
  • Basic account info (open_id)

Data We Process

  • Video content: Scripts, voiceovers, assembled videos (processed locally, not stored by us)
  • Posting metadata: Timestamps, video IDs, platform responses
  • Analytics: Views, likes, shares (fetched via TikTok API for logging)

Data We Store

  • OAuth tokens: Encrypted, stored locally in your n8n instance only
  • Execution logs: Trend topics, script hooks, captions (Google Sheets, your account)
  • No personal data is sent to third parties except TikTok API

Data We Do NOT Collect

  • No browsing history
  • No device identifiers beyond what TikTok provides
  • No location data
  • No contacts or messages

Your Rights

  • Revoke access anytime: TikTok Settings → Security → Authorized Apps → Remove
  • Delete data: Remove n8n workflow + Google Sheet
  • No data retention beyond your local storage

Security

  • Tokens encrypted at rest (n8n credential store)
  • HTTPS for all API communication
  • No credential logging

Children's Privacy

Not directed at users under 13. TikTok requires 13+.
